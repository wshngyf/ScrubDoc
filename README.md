# ScrubDoc

**简体中文** | [English](README.en.md)

Windows 离线文档脱敏工具。将文档中的指定敏感词替换为随机标记，供 AI 或联网工具处理，再使用对应 CSV 文件将标记还原为真实内容。

```text
原始文档 → 本地脱敏 → 处理后的文档 → 本地还原
                ↓                     ↑
                └── 敏感词映射.csv ────┘
```

所有解析、替换、图片删除及还原操作均在本机执行，无需账号、网络或 Microsoft Office。当前客户端一次处理一个文档。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 及以上，64 位 |
| 文件格式 | DOCX、TXT |
| TXT 编码 | UTF-8、带 BOM 的 UTF-8、GB18030 |
| 独立客户端 | 无需安装 Python |
| 源码运行 | Python 3.10 及以上，包含 Tkinter |

当前在 Windows 11 环境完成开发及测试；Windows 10 实机兼容性尚待验证。

## 功能

- 敏感词新增、修改、删除、批量录入、导入和导出。
- 自动生成随机替换标记，支持手动调整。
- 勾选需要处理的敏感词，同一词使用同一标记。
- 检查当前文档中各敏感词的命中次数，包含零命中项。
- 一次替换全部勾选词的所有命中位置，导出新副本。
- 一键删除 DOCX 图片，也可以只去图片而不替换文字。
- 自动导出本次敏感词映射 CSV，供后续还原。
- 通过“处理后的文档 + 对应 CSV”检查并还原标记。
- 左侧流程导航、可滚动词库与结果区域、统一窗口及程序图标。

## 使用流程

以下截图来自当前桌面界面，词语、路径及结果数字均为演示数据。按左侧 01 → 02 → 03 的顺序操作即可。

### 1. 管理敏感词与映射

进入左侧 **01 敏感词与映射** 页面：先录入词语，检查右侧替换标记，再在“启用”列勾选需要处理的词。

![敏感词管理页面：左侧选择第一步，中间管理词语和替换标记](docs/images/01-terms.png)

图 1：蓝色“批量新增”按钮用于一次录入多个词；词表中的勾选状态决定哪些词参与脱敏。

- **新增**：录入一个敏感词。
- **批量新增**：每行一个词，输入或粘贴后点击“保存全部”，也支持 `Ctrl+Enter`。空行忽略，重复词自动跳过。
- **修改**：选中词条后修改词语及替换标记；也可以双击词条。
- **删除**：删除选中的词条。
- **重新生成标记**：为选中的词条重新生成随机标记；未选中行时作用于全部词条。
- **启用列**：单击切换勾选状态，也可使用“全选”“全不选”。只有启用的词参与检查及脱敏。

默认标记示例：

```text
张三 → 【敏感项_A7k2M9x4Qp】
秘密项目 → 【敏感项_B8n3R6y5Ts】
```

支持将标记手动改为 `mMx` 等自定义字符串。标记必须唯一、非空，不得与原词相同，不得相互包含，也不得包含当前启用的敏感词。导出时会检查标记是否已存在于原文，避免还原时混淆。

批量录入时，每行填写一个词。完成后点击窗口底部 **保存全部**，或者按 `Ctrl+Enter`。

![批量新增对话框：每行一个词，底部点击保存全部](docs/images/02-bulk-add.png)

图 2：空行和重复词自动跳过。保存后回到词表，确认新增词条已出现。

匹配按原文精确执行，区分大小写，不做模糊匹配、同义词扩展或自动语义识别。

### 2. 选择文档并检查命中

进入“脱敏导出”页面：

1. 点击“选择文档”，选择一个 DOCX 或 TXT 文件。
2. 点击“检查命中”。
3. 查看当前文档中每个启用词的出现次数。

![检查命中页面：选择一个文档后，查看每个启用词的命中数量](docs/images/03-check-hits.png)

图 3：依次点击顶部 **选择文档 → 检查命中**，在下方结果区核对各词出现次数。检查结果仅显示当前文件的次数，不显示上下文，也不跨文件汇总。

如果词库同时包含“秘密”和“秘密项目”，命中检查分别统计两个词；实际替换时优先匹配较长词，因此次数之和可能大于实际替换次数。

### 3. 导出脱敏文档

按需勾选“去除全部图片”，点击“全部替换并导出”，选择输出目录。

程序创建独立任务子目录，例如：

```text
ScrubDoc_20261028_214843_a1b2c3/
├── 可交给AI/
│   └── 001_文档名称_脱敏.docx
└── 仅本地保存_含敏感信息/
    └── 敏感词映射.csv
```

![脱敏导出结果：可选去除图片，结果区显示输出目录及敏感词映射文件](docs/images/04-export.png)

图 4：按需勾选 **去除全部图片**，再点击 **全部替换并导出** 并选择输出目录。完成后核对结果区是否显示成功，以及替换、图片删除数量。原文件不被覆盖；失败时显示原因。

只向外部工具提供检查后的脱敏副本。文件名仍包含原文件名称，上传前也应检查文件名是否泄露信息。映射 CSV 含真实原文，应保存在本机。

### 4. 使用 AI 或其他工具处理

“脱敏导出”页面展示了 AI 提示词，可选中文字后自行复制，没有独立的提示词按钮。

处理时应要求对方完整保留替换标记，不改写、不翻译、不拆分、不猜测其内容。提示词只能降低标记被改动的概率，不能保证处理工具一定遵守。

软件不内置 AI 服务，不会自动上传文档或发起网络请求。

### 5. 检查与还原

进入“检查与还原”页面：

1. 选择“处理后的文档”。
2. 选择脱敏时对应的“敏感词映射.csv”。
3. 点击“检查替换标记并还原”。
4. 检查通过后，选择另存位置，生成还原副本。

![检查与还原页面：上方分别选择处理后的文档和对应CSV，下方查看还原结果](docs/images/05-restore.png)

图 5：上方第一行选择 **处理后的文档**，第二行选择本次脱敏生成的 **敏感词映射.csv**。点击蓝色按钮后，检查通过会弹出另存窗口；保存成功后，下方显示还原次数和输出位置。

检查结果展示每个标记的当前命中次数：

- **正常标记**：按 CSV 中的映射恢复，重复出现的标记一并还原。
- **缺失标记**：提示确认；继续时仅恢复仍存在的标记，不强行插回删除的内容。
- **未知标准标记**：阻止还原，需选择正确的 CSV 或修正文档。
- **没有匹配标记**：提示无法还原。

未知标记检测针对默认的 `【敏感项_字母数字】` 形式。自定义标记被改写后，不一定能识别为未知标记，需要人工检查。

还原输出与处理后文档保持相同文件类型，不能覆盖已有文件或源文件。

## 词库与 CSV 格式

### 词库导入

支持 TXT 和 CSV：TXT 每行一个敏感词；CSV 使用第一列作为敏感词，可包含“敏感词”或 `term` 表头。空词忽略、重复词去重。

导入词库会生成新的随机标记，**不会加载 CSV 第二列作为当前词库标记**。如果要还原历史文档，应在还原页面直接选择对应 CSV。

### 词库导出

- CSV：导出当前词库中的全部词语和替换标记，包含未启用项。
- TXT：仅导出词语，每行一个，不包含替换关系。

### 还原用映射文件

必须包含两列：

```csv
敏感词,替换标记
张三,【敏感项_A7k2M9x4Qp】
秘密项目,mMx
```

推荐使用软件导出的 UTF-8 BOM CSV。含逗号的字段应按 CSV 规范使用双引号包裹。

只有一列敏感词的 TXT/CSV 无法还原。重复标记、空字段、同一敏感词对应不同标记会被拒绝。旧版两列“替换清单.csv”仍可用于还原，无需 JSON 还原包。

**优先使用脱敏时自动生成的映射文件。** 后续修改词库、重新生成标记或重启软件后，词库中的标记可能变化，不能代替当次映射。

## 本地数据与隐私

- 默认词库保存于 `%LOCALAPPDATA%\ScrubDoc\terms.json`；环境变量不可用时使用用户目录。
- 持久化词库仅保存词语，重启后重新生成随机标记。
- 映射 CSV 为明文，不提供加密；掌握该文件的人可以恢复对应敏感内容。
- 源文件、脱敏文件和还原文件分别保留，不提供安全擦除原件功能。
- 不记录文档正文日志。测试输出与映射文件由使用者自行保管、清理。

## 支持范围与限制

### 文档内容

DOCX 支持处理 Word 文本，包括正文、表格、页眉页脚、脚注、尾注及文本框。脱敏导出会清除批注内容、修订删除内容及常见文档属性，保留修订新增文字；不保留原数字签名的有效性。

图片删除会移除支持的图片对象及 `word/media` 媒体文件。删除后的图片无法通过 CSV 恢复，只能从保留的原件找回。

图表、SmartArt、公式、OLE、附件、外链及其他复杂对象不保证完整覆盖；图片内文字不做 OCR。自定义 XML 或其他非正文数据也不保证脱敏。必须人工检查有此类内容的文档。

当前不支持 DOC、RTF、ODT、PDF、扫描件或加密 DOCX，也不提供自动发现全部敏感信息的保证。

### 还原与排版

还原是把处理后文档里的替换标记恢复为原词，保留处理工具对其他内容的修改。它不等于恢复原始文件的全部字节、原分页或原版式。

替换文字长度改变可能导致换行及分页变化。处理后只得到纯文本时，无法自动重建原 Word 格式。保留真实姓名等信息所需的映射文件丢失后，无法从随机标记推回原文。

## 常见问题

**检查命中次数为什么大于替换次数？**

相互包含的词独立统计，执行时优先替换较长词，避免同一段文本重复替换。

**还原提示标记缺失怎么办？**

先核对 CSV 是否对应本次任务，再检查处理工具是否删除或改写了标记。允许只还原现存标记时，可确认继续；缺失内容不会自动补回。

**只有词库，没有替换标记，能还原吗？**

不能。需要脱敏时实际使用的两列映射文件。

**能保证上传的文档完全没有敏感信息吗？**

不能。当前以用户指定词库进行精确替换，未配置词语、文件名和未覆盖的复杂对象可能仍含敏感信息，需要人工检查。
